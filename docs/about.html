About

What Ombuntu is, and what it is not.

Ombuntu is the Omarchy Hyprland desktop running on Ubuntu 26.04 instead of Arch Linux. Omarchy is an opinionated, keyboard-driven desktop built on Hyprland: a tiling window manager, a launcher, a bar, themes, and a menu that installs and configures software for you. Ombuntu keeps all of that and swaps the Arch-specific parts for Ubuntu ones.

How it works

Upstream Omarchy is cloned at a fixed tag into ~/.local/share/omarchy and left unmodified. A small overlay is laid on top: apt instead of pacman, Ubuntu packages or vendor repositories in place of the AUR, and fixes for a few Ubuntu packaging quirks. Updates re-apply the overlay, so moving to a newer Omarchy is a matter of changing one tag.

What is different

  • apt instead of pacman and yay; no AUR.
  • Walker, Elephant, Satty and mise are pinned, checksummed GitHub releases. wlsunset, wf-recorder, nmtui, Blueman and pulsemixer stand in for hyprsunset, gpu-screen-recorder, impala, bluetui and wiremix.
  • Omarchy's plugin surface (hooks, menu extensions, remote themes) is disabled for security.
  • Telemetry from Canonical and browser vendors is turned off. See Privacy.
  • Menu entries with no Ubuntu path are removed rather than left to fail.
  • Not installed: Spotify, Obsidian, Typora, LocalSend, Pinta (offered under Install, Apps), 1Password, Docker, snapper, limine, Plymouth, SDDM, and Omarchy's own-company web apps.

Naming

Everything Ombuntu adds is called Ombuntu. The upstream engine keeps its omarchy-* command names, because its scripts call each other by them; the ombuntu command is the same dispatcher.

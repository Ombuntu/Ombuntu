About

What Ombuntu is, what it is built on, and what it leaves out.

Ombuntu is a pre-configured desktop for Ubuntu 26.04: a tiling window manager (Hyprland), a launcher, a status bar, a lock screen, themes, and one menu that installs software and changes settings, all set up to work together the moment you log in. It is keyboard-driven, fast, and opinionated so you do not have to assemble it yourself.

It is also deliberately conservative about security and privacy. Software comes only from Ubuntu's archive, vendor-signed repositories, or pinned and checksummed releases. Telemetry from the operating system and the browsers is switched off. Nothing downloads and runs code from the internet at runtime, and the convenience shortcuts that trade security for a click (passwordless sudo, autologin, remembered screen-share permissions) are not offered. The privacy and security page lists every such choice with the file behind it.

Built on Omarchy

The desktop itself is Omarchy, DHH's Hyprland configuration for Arch Linux, which Ombuntu installs unmodified at a pinned commit and adapts to Ubuntu with an overlay: apt in place of pacman, Ubuntu packages or vendor repositories in place of the AUR, fixes for Ubuntu packaging quirks, and the security and privacy changes above. Omarchy's plugin surface (hooks, menu extensions, remote themes) is disabled, and menu entries with no safe Ubuntu path are removed rather than left to fail. Updates re-apply the overlay, so moving to a newer Omarchy is a matter of changing one pin.

What is different from Omarchy

  • apt instead of pacman and yay; no AUR, no curl | sh.
  • Walker, Elephant, Satty and mise are pinned, checksummed releases. wlsunset, wf-recorder, nmtui, Blueman and pulsemixer stand in for hyprsunset, gpu-screen-recorder, impala, bluetui and wiremix.
  • Hooks, menu extensions and remote themes are disabled; passwordless sudo and autologin are not offered.
  • Telemetry off; browsers store passwords in the keyring; screen sharing asks every time; Omarchy's command directory sits last in PATH.
  • Not installed: Spotify, Obsidian, Typora, LocalSend, Pinta (offered under Install, Apps), 1Password, Docker, snapper, limine, Plymouth, SDDM, and Omarchy's own-company web apps.

Naming

Everything Ombuntu adds is called Ombuntu. The upstream engine keeps its omarchy-* command names, because its scripts call each other by them; the ombuntu command is the same dispatcher.

Ombuntu keyboard cheatsheet

The essentials for your first week. Everything else is one keypress away.

Super is the Windows key (⌘ on a Mac keyboard). Nearly every shortcut starts with it. Press Super+K any time for the full searchable list.

Start here

Super+SpaceOpen any app start typing its name, Enter to launch
Super+EnterTerminal
Super+Shift+BWeb browser
Super+Shift+FFile manager
Super+WClose the current window
Super+Alt+SpaceOmbuntu menu themes, settings, install, update, power
Super+EscLock, sleep, log out, restart, shut down
Super+KEvery keyboard shortcut, searchable

Windows

Super+← → ↑ ↓Move focus between windows
Super+Shift+← → ↑ ↓Swap the window with its neighbour
Super+FFull screen on / off
Super+TFloat the window / tile it again
Super+JFlip the split (side by side ↔ stacked)
Super+- / =Make the window narrower / wider
Super+dragLeft button moves, right button resizes
Alt+TabCycle through windows on this workspace

Workspaces

Super+1 … 9 0Go to workspace 1 to 10 they appear in the top bar as you use them
Super+Shift+1 … 0Send the current window there
Super+TabNext workspace add Shift for previous
Super+scrollScroll through workspaces
Super+SScratchpad: a hidden workspace that drops over the top Super + Alt + S sends a window into it

Copy, paste and text

Super+C / V / XCopy / paste / cut, works in the terminal too
Super+Ctrl+VClipboard history
Super+Ctrl+EEmoji picker
Caps Lock then two keysCompose key for accents and symbols Caps, ', e → é   Caps, -, > → →

Screenshots and capture

PrintScreenshot: drag a region, or click a window saved to Pictures and copied; click the notification to annotate
Alt+PrintScreen recording (press again to stop)
Super+PrintColour picker
Super+Ctrl+PrintCopy text out of anything on screen (OCR)

Look and feel

Super+Shift+Ctrl+SpacePick a theme
Super+Ctrl+SpaceNext wallpaper
Super+Shift+SpaceHide / show the top bar
Super+Ctrl+NNight light (warmer screen)
Super+BackspaceWindow transparency on / off

System and hardware

Super+Ctrl+WWi-Fi
Super+Ctrl+BBluetooth
Super+Ctrl+AAudio devices and volume
Super+Ctrl+TActivity monitor (CPU, memory, processes)
Super+Ctrl+LLock the screen
Super+,Dismiss a notification add Shift to clear them all
Ctrl+Alt+DeleteClose every window

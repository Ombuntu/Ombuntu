Uninstall

Back to plain Xubuntu. XFCE was never touched, so this is short.

Remove the login entry, Omarchy, and the configuration Ombuntu wrote:

sudo rm /usr/share/wayland-sessions/ombuntu.desktop
rm -rf ~/.local/share/omarchy ~/.local/share/ombuntu ~/.config/omarchy ~/.local/state/omarchy
rm -rf ~/.config/{hypr,waybar,walker,elephant,mako,swayosd,alacritty,uwsm}
rm -f ~/.local/bin/{walker,elephant,satty,mise,omarchy,ombuntu}
rm -f ~/.config/Hyprland-mimeapps.list ~/.config/hyprland-mimeapps.list
mv ~/.bashrc.pre-omarchy ~/.bashrc

Restore the user services Ombuntu masked:

systemctl --user unmask waybar.service hypridle.service foot-server.service foot-server.socket hyprpolkitagent.service update-notifier-crash.path update-notifier-crash.service

Then remove whichever packages from install/packages.list in the repository you do not want, with sudo apt remove. Other Omarchy files under ~/.config (btop, fastfetch, starship, tmux, git, fontconfig) are harmless to keep or delete.

Privacy settings

The telemetry changes stay unless you undo them. To return to Ubuntu defaults: set enabled=1 in /etc/default/apport and sudo apt install whoopsie; pro config set apt_news=true; delete /etc/firefox/policies/policies.json and the ombuntu-privacy*.json files under each browser's policies/managed directory.

Ombuntu

A pre-configured, keyboard-driven Hyprland desktop for Ubuntu. Secure and private by default.

On a fresh Ubuntu or Xubuntu 26.04, run:

curl -fsSL https://ombuntu.org/install.sh | bash

Then log out and choose Ombuntu at the login screen. Your existing desktop stays installed. Prefer to read first? install.sh is short.

What you get

  • A tiling window manager, an app launcher, a status bar, a lock screen and nineteen themes, all configured and consistent.
  • One menu (Super + Alt + Space) to install software, change themes and settings, and manage the system.
  • Everything comes from Ubuntu's archive, vendor-signed repositories, or pinned and checksummed releases.

Off by default

  • Telemetry. Crash reporting and usage statistics to Canonical, Ubuntu Pro adverts, and data collection in Firefox, Chrome, Chromium, Brave, Edge and Vivaldi.
  • Remote code. No curl | sh installers, no plugin hooks or menu extensions, no themes cloned from arbitrary repositories.
  • Unverified downloads. Every archive is checksummed, every apt key checked against a pinned fingerprint, every upstream pinned to a commit.
  • Convenience shortcuts that cost security. No passwordless sudo, no autologin, no remembered screen-share permissions, no plain-text password storage in browsers.

Each item is a file you can see and reverse; the privacy and security page lists them all.
